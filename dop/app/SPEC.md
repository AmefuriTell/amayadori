# アプリの今の形

DOP-C02 の問題を解く静的なページ。ビルドしない（素の HTML・CSS・ES modules）。GitHub Pages の `/amayadori/dop/app/` に置く。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 入口。`version:start`〜`end` の間（版の meta・CSS・import map・main.js）は `node dop/tools/app.mjs stamp` が書く。手で直さない |
| `style.css` | 見た目（明るい・暗いの配色は端末の設定に従う） |
| `src/main.js` | 画面（読み込み・1 問ずつの表示・答えた後の解説・結果・記録・読み上げ・版のお知らせ） |
| `src/ui/*.js` | 画面の部品（F-0003 で main.js から切り出した）: `el.js` 要素を作る、`version.js` 版のお知らせ、`glossary.js` 事典の表示、`speech.js` 読み上げ |
| `src/storage.js` | localStorage の読み書き（使えない時も例外を外に出さない） |
| `src/logic/*.js` | 画面に頼らない計算（採点・記録・報告・書き出し・言葉・読み上げの文・進み具合）。unit で試す |
| `public/questions.json` | 配信用の問題。`node dop/tools/app.mjs data` が bank から作る。手で書かない |
| `public/version.json` | 最新の版の番号。`app.mjs stamp` が書く |
| `public/diagrams/<問題 ID>.svg` | 構成図（P-015）。`dg.mjs publish` が diagrams/ の図の元から描く。手で書かない |
| `public/glossary.json` | サービス事典（名前 → ページの表とページ）。`app.mjs data` が glossary/services/ から作る |
| `test/*.test.js`・`e2e/*.e2e.js` | 試験。名前の先頭は「<項目 ID> <AC>」 |

## 画面

- 1 問ずつ。上に「i / n」。問題文と選択肢は日本語（日本語版の無い問題は英語で「日本語版はまだありません」）。「English」で英語に切り替え、選んだ言葉は端末に残る（A-0008）。
- 1 つ選ぶ問題はラジオ、複数選ぶ問題はチェックで「n つ選ぶ」。そろうまで「答える」を押せない。
- 「分からない」（A-0012）: いつでも押せ、選んだ物は捨てて無回答の不正解として記録し（skipped: true）、正解と解説を出す。
- 答えると、正誤・正解の選択肢の印・全選択肢の解説・補足（note がある問題、A-0007）・出典の原文とリンク。「誤りを報告」（端末に残し、GitHub の issue の下書きを開ける）。「次へ」。
- 最後は正解の数。「もう一度」。
- low_confidence の問題は「AI の確信が低い」の印。報告した問題は「報告済み」。
- 読み込み直しても、解いていた問題（答えた後なら答えた画面、結果なら結果）から続く。問題 ID で覚える（A-0010）。
- 「読み上げ」（A-0009）: オンの間、問題が出たら問題文と選択肢、答えたら正誤と解説の要約をブラウザの声で読む。「もう一度」・速さ 0.8〜1.5。サービス名とリージョンのコードは読み方に置き換える。
- 「記録」: ドメイン別の正答率（問題ごとの最新の答え）。「記録を書き出す」で答えと報告を JSON のファイルに保存（L1 の learn weak の入力、A-0005）。「記録を消す」。
- 画面の下に「版 <番号>」。サーバーの版が新しければ上に「新しい版があります。読み込み直す」（A-0011）。JS と CSS は版の番号付きの URL で読むので、読み込み直せば必ず新しい版になる。
- サービス事典（A-0013、P-014）: 問題のサービス名のうち事典にある物はボタン。押すと事典のページ（読み・要約・主な機能・試験のポイント・似たサービスとの違い・出典）が開く。上の「事典」で一覧。事典は問題と別のファイルで、問題からは名前で引く。
- 構成図（A-0014、P-015）: 図のある問題では、答えた後の解説の後に「構成図」。図の中のサービスの箱を押すと事典のページが開く（事典にある物だけ）。図は白い板の上に出す。
- 模試（A-0003）: 上の「模試」。ドメインの割合どおりに最大 75 問・制限時間 180 分。途中では正誤も解説も出さず、「前へ」「次へ」で動ける。「終える」か時間切れで採点し、正答率・ドメイン別・間違えた（答えなかった）問題の正解と解説を出す。答えは記録に足す（mock: true）。途中の状態は dop:v1:mock に残り、読み込み直しても続く。本番の換算点は出さない。
- 間違えた問題だけ解き直す（A-0004）: 「記録」の「間違えた問題を解き直す（n 問）」で、最新の答えが不正解（分からないを含む）の問題だけを解く画面にする。上に「間違えた問題だけ（n 問）」と「やめる」。一覧は始めた時に決めて dop:v1:retry に残す（途中で正解しても減らさない）。記録の正答率の表と模試は全部の問題（state.allQuestions）で数える。

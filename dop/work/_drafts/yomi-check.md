DOP 問題集の講義 {TASK}（項目 {ID}）の音声を作る前に、読み違いが無いかを確かめて直してください。音声は VOICEVOX ENGINE が作りますが、漢字を別の読みで読むことがあります（例: 値 を「ね」、行 を「くだり」、例 を「たとえ」、何 を「なに」、並べて を「なべて」）。

**ファイル**: /home/user/amayadori/dop/work/{ID}/yomi.json
形: `{ hash, checked, slides: [{ id, lines: [{ who, text, say?, yomi }] }] }`
- text = 台本の行（画面に出す文。変えない）
- yomi = エンジンが実際に読む読み（ひらがな。空白はアクセントの区切り）
- say = 読ませる文。読み違いがある行にだけ足す（前の工程で足した say が残っている行もある。それも正しいか見る）

**やること**
1. 全部の行について、text の正しい読みと yomi を照らす。
2. 読み違いがあれば、その行に `say` を足す。say は text をそのまま写し、**読み違いの漢字の語だけ**をひらがなに置き換えた文にする（空白は足さない）。漢字を全部ひらがなにしない（抑揚が崩れる）。カタカナ・句読点は変えない（ツールが拒む）。
3. 直したら `cd /home/user/amayadori/dop && node tools/lec.mjs yomi {ID}` で読みを作り直し、直した行の yomi が正しくなったか見る。
4. 全部よければ `node tools/lec.mjs yomi {ID} --done`。

**読み違いに数えない物（エンジンの表記のくせ）**: 長音が母音で書かれる（説明 → せつめえ、公式 → こおしき、パラメーター → ぱらめえたあ）、助詞の「は」→ わ・「を」→ お・「へ」→ え、句読点での区切り。
**読み違いに数える物**: 漢字の読みの誤り（音読み・訓読みの取り違え、別の語としての読み）、数や助数詞の読みの誤り。カタカナの語がおかしく読まれる時は say では直せないので、返事で報告だけする。

ほかのファイルは書き換えず、git も使わないでください。
**返事（短く）**: 直した行の数、直した語の一覧（text の語 → 読み）、直せずに報告だけの物。
